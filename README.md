# AI Skills — Biblioteca pessoal

Catálogo de Skills, referências e materiais autorais para agentes de IA.

## Política de inclusão
- Verificar origem, licença, segurança, compatibilidade e versão antes de incorporar código de terceiros.
- Não confundir referência catalogada com Skill instalada ou testada.
- Não executar scripts externos automaticamente.
- Não publicar material marcado como confidencial sem revisão e autorização.
