# Exemplo de instruções para um projeto consumidor do Ai-skills

- Orçamento adicional: R$ 0. Não utilizar automaticamente API, modelo ou hospedagem pagos.
- Antes de trabalhar, ler último checkpoint e git status; pesquisar somente arquivos relevantes.
- Consultar VNSANTS/Ai-skills/INDEX.md para escolher **somente** Skills pertinentes; referências externas não são autorização para instalar.
- Usar `AGENTS.md` e `SKILL.md` do projeto respeitando segurança, dados privados e aprovação de mudanças destrutivas.
- Sintetizar logs, agrupar chamadas independentes e evitar auditorias/testes repetidos sem mudança.
- Testar componentes alterados e gates críticos; registrar resultados reais, não inventar economia de tokens.
- Registrar no checkpoint branch, commit, decisões, testes, bloqueios e próximos passos.
