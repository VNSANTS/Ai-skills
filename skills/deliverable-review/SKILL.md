# Revisão da entrega

## Antes de revisar

Use o pedido original e as correções posteriores para identificar os critérios de aceite. Localize os arquivos finais no destino solicitado. Para uma entrega curta e de baixo risco, abra o resultado e confira conteúdo, formato e acesso.

## Verifique a entrega como destinatário

1. Associe cada requisito obrigatório a uma verificação observável. Inclua quantidade de arquivos, formato e destino quando especificados. Respeite os limites de acesso e compartilhamento durante os testes.
2. Abra cada entrega pela via normal de uso. Em dados, confira unidades, cobertura, estrutura e precisão. Em documentos, valide afirmações e referências contra a fonte e leia a versão exportada. Entre arquivos, confronte os mesmos totais, eventos, datas e exceções. Em código, exercite o fluxo pedido. Em links, verifique o destino e informe se o acesso do destinatário ficou pendente.
3. Para um resultado de alto impacto, busque uma conferência independente a partir das entradas brutas. Um segundo cálculo em centavos, por exemplo, pode conferir um relatório calculado com decimais. Registre se houve outro revisor ou se o próprio executor aplicou outro método e investigue diferenças entre os resultados.
4. Classifique cada critério como **verificado**, **falhou** ou **não verificado**, com método e evidência da versão final. Se houver falha, corrija a causa dentro do escopo e repita as verificações afetadas, inclusive nos arquivos derivados.
5. Entregue o resultado e as pendências materiais. Se um requisito permanecer aberto, informe o efeito e a evidência ou decisão necessária para encerrá-lo.

Consulte [o exemplo](references/example.md) para uma revisão de dados com um item de acesso pendente.
