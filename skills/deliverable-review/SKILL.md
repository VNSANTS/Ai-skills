# Revisão da entrega

## Antes de revisar

Use o pedido original e as correções posteriores como fonte dos critérios. Identifique a versão final que o destinatário vai receber. Para uma entrega curta e de baixo risco, basta verificar conteúdo, formato e acesso.

## Verifique a entrega como destinatário

1. Escreva um critério observável para cada requisito. Mantenha preferências declaradas separadas dos requisitos obrigatórios.
2. Abra a versão final e compare com o solicitado. Em documentos, verifique conteúdo, legibilidade e exportação. Em dados, confira unidades, cálculos e reconciliação. Em código, exercite o fluxo pretendido com os testes disponíveis. Em links, verifique o destino e informe se o acesso do destinatário não pôde ser confirmado.
3. Associe cada critério obrigatório à evidência da mesma versão. Use os estados **verificado**, **falhou** e **não verificado**. Registre o método e, quando útil, a página, célula, comando ou revisão.
4. Corrija falhas dentro do escopo. Reexecute as verificações que dependem da mudança e valide novamente o arquivo exportado ou publicado quando esse for o objeto entregue.
5. Relate a entrega e pendências materiais. Se um requisito obrigatório continuar aberto, indique impacto e evidência necessária para encerrá-lo.

Consulte [o exemplo](references/example.md) para uma revisão de dados com um item de acesso pendente.
