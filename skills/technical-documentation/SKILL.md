# Technical Documentation

1. Determine de onde o leitor parte e como reconhecerá sucesso. Liste pré-requisitos e permissões reais.
2. Escreva etapas na ordem operacional, com exemplos mínimos, resultado esperado e recuperação para falhas comuns.
3. Execute as instruções em ambiente equivalente quando possível. Registre versão e quais passos foram validados.
